## Status

This is a local, single-host Docker Swarm and Jenkins CI/CD simulation. Its goal is to demonstrate deployment flow, approval gates, rolling-update concepts, environment separation, and infrastructure automation. It is not a supported production platform and is retained as a legacy-platform/DevOps learning lab, complementary to the Kubernetes showcase.
